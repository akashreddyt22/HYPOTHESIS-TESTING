# Hypothesis Testing: Bombay Hospitality Ltd.

## Background
Bombay Hospitality Ltd. operates a franchise model for producing exotic 
Norwegian dinners across New England. The theoretical weekly operating 
cost model is:

**W = $1,000 + $5X**

where X is the number of units produced per week. Restaurant owners 
report that actual weekly operating costs are higher than this model 
predicts.

## Objective
Use hypothesis testing to investigate the restaurant owners' claim that 
weekly operating costs have increased.

## Data
- Theoretical cost model: W = $1,000 + $5X
- Sample: 25 restaurants, mean weekly cost = Rs. 3,050
- X ~ Normal distribution, μ = 600 units, σ = 25 units

## Tasks
1. State the hypotheses (H0 and H1)
2. Calculate the test statistic (z)
3. Determine the critical value
4. Make a decision and conclusion
